# Ghar Finds catalog

The bio-link catalog for two Instagram accounts, @jugaadhouse0001 (Jugaad House) and @handyhouse0001
(Handy House). Every post shows a product number; https://gharfinds.github.io/ finds it.

- `data/products/NNNN.yaml`: one product per file (number, store, product link, affiliate link, photos, features)
- `site.yaml`: catalog name and colours
- `scripts/build_site.py`: builds the static site; `.github/workflows/pages.yml` publishes it on every push

Ad disclosure: the "Buy" links are affiliate links. Products are sold and shipped by the stores and their sellers.
