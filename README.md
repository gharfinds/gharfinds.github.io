# Jugaad House / Handy House catalog

The bio-link catalog for two Instagram accounts. Every post shows a product number; this page finds it.

- `data/products/NNNN.yaml`: one product per file (number, Meesho link, affiliate link, photos, features)
- `site.yaml`: account names and colours
- `scripts/build_site.py`: builds the static site; `.github/workflows/pages.yml` publishes it on every push

Ad disclosure: "Buy on Meesho" links are affiliate links. Products are sold and shipped by Meesho sellers.
